# Personas — 01-task-manager

## Task Manager User

- **Role**: Sole end user of the personal task manager (no roles, accounts, or permissions differentiation)
- **Goals**:
  - Quickly capture tasks so nothing gets forgotten
  - See all current tasks at a glance
- **Context**: Uses the web application in a browser to manage a personal to-do list; no multi-user or collaboration needs
- **Pain Points Addressed**: Forgetting tasks, no single place to see everything that needs doing

This is the single persona referenced by all stories in `stories.md`.
